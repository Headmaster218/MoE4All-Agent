# 语言与配色

MoE4All Agent 支持中文和 English，提供白色（明亮模式）、森林绿、黑色、灰色（三种暗色模式）。森林绿采用中性深灰底色与低饱和绿强调色；新建 profile 默认使用森林绿。已有用户设置不被初始化覆盖。

语言、配色与 Agent 检查更新集中在设置的通用页面。桌面内容延伸到原标题栏区域，不再重复显示产品名称；地球图标与 Windows 窗口按钮共用右上角区域，不另占一行。会话、详情和侧栏标题的空白可拖动窗口，按钮仍可点击；保留原生最小化、最大化、关闭、缩放边框和窗口菜单。内容为窗口按钮预留水平空间，随 DPI 和页面缩放调整。旧 WebView2 缺少拖动区域支持时退回标准标题栏。外观中的“自动跟随系统”在系统明亮时使用白色，暗色时使用用户选定的森林绿、黑色或灰色；自动模式下点击暗色选项只更换暗色偏好，点击白色则退出自动模式。本地应用偏好存入当前 Agent 独立数据目录中的 `home/settings.yaml`，包含 `ui-theme.preference` 与 `ui-theme.darkPreference`；`desktop-appearance.json` 缓存启动页所需的语言、主题及自动偏好，不替代 Host settings。两者均不读写生产 DSH 的设置。

发现更新、手动检查、下载、校验、解压和错误提示均使用 DSH 的 Modal 与语义颜色。检测到更新后需要用户点击“下载并安装”；关闭弹窗不会取消后台下载，可从设置中重新查看进度。浏览器模式不显示桌面更新操作。首次启动与启动失败页面使用内嵌 HTML，配色与应用一致，提供阶段说明、进度、详情和日志入口。加载应用前的主题引导也使用同一组 palette token，避免短暂显示另一套配色。

Windows 标题栏通过 DWM 跟随应用配色。文件、模型和目录选择统一使用 Windows Common Item Dialog（Explorer 的地址栏、导航、搜索和列表），目录模式不再使用简化树或网页文件浏览器。选择窗口归属 Agent 主窗口，位于设置和首次引导之上；取消不改变路径。白色主题请求原生亮色，三种暗色请求原生暗色；高对比度保留系统设置。标题栏明确跟随明暗偏好，但 Explorer 内部控件仍可能使用系统主题（例如系统暗色而 Agent 白色），不能保证所有 Windows 构建都支持进程级覆盖。旧系统或缺少可选主题 API 时退化到系统默认。主题作用域仅限当前进程和本次选择，不修改系统设置或其他应用。

请求选择前恢复并激活 Agent 自己的窗口（原先最大化后最小化的窗口也保留恢复状态），不设全局置顶。选择期间 Agent 主窗口暂时禁用，因此设置、首次引导及其内容层不能盖过选择器；完成后由 Windows 恢复交互。定向回归覆盖三种选择模式的真实选中与取消，以及窗口归属、模态禁用和从最小化恢复。

内置插件使用同一组语义颜色。定时任务的表单、状态和错误提示提供中英文本；TTS 的自动语言跟随应用语言，显式选择的 TTS 语言仍保留独立设置。Mneme、模型管理、手机连接、插件市场和 EasyRewrite 沿用各自双语内容并跟随应用外观。Brave 搜索插件没有独立客户端界面，不额外添加一套语言或配色设置。

正文、说明小字、按钮文字和状态提示的颜色组合以最低 4.5:1 对比度为测试标准；控件强边框为 3:1。禁用状态保留清晰文字，通过底色和交互状态区分，不靠整体降透明度。已验证的颜色组合不等于对所有第三方插件或图像内容的可访问性保证。

UI 验证使用隔离 profile，不启动推理引擎，不下载模型，不接触生产数据。测试生成的日志和截图位于忽略的 `artifacts/appearance/`，不随产品发布。

客户端验证脚本为 `harness/scripts/Test-AgentAppearance.mjs`，需要已构建的 DSH 和 Playwright。传入隔离应用的 URL 与输出目录，例如 `node harness/scripts/Test-AgentAppearance.mjs http://127.0.0.1:17374/ artifacts/appearance/web`。脚本会切换并保存测试 profile 的语言和配色，检查跟随系统与重载、打开设置与记忆面板，并通过模拟桌面消息核验更新界面；不执行真实更新，不启动引擎或创建定时任务，不应对生产 profile 执行。

启动器的 `--startup-ui-test` 核验原生 fallback 布局、颜色对比和支持时的 DWM 标题栏颜色，并导出内嵌启动页与状态。`Test-AgentStartupAppearance.mjs` 读取这些输出，核验中英、四种配色、四种尺寸及启动、解压、失败状态的进度条位置和横向溢出。此类 UI 验证不等于整合 ZIP 的更新与回退安装验证。
