# Agent 本地编译与功能验证

本次针对[选定的 DSH 功能](../../../roadmap/dsh-feature-selection.md)编译、实际使用并修复问题，不是升级整个 DSH，不是正式发布。运行代码固定于 Agent `6921d66`、DSH `5bfeb6f`；八个插件维持主仓固定的 commit，未改插件业务源码或独立 Engine。

## 环境与隔离

- 使用 Node 24.9.0、pnpm 11.7.0 和冻结的依赖锁。
- 使用现成的 Qwen3.6 35B GGUF 与 Engine 1.0.3，2 slots、16K context、ubatch 1024；未下载模型。本次不是性能 benchmark，不能拿构建并行期间的 tok/s 与发行基准比较。
- 测试 Agent、profile、浏览器、工作区和端口与生产 DSH 分离；没有复制生产会话或凭据，也没有停止生产服务。
- 输入文件、Git 仓库与 PPTX 都是本轮合成 fixture；不使用真实用户文件。

## 本次发现并修复

1. **完整构建的测试类型错误**：HostApi mock 缺少新方法，部分测试未正确收窄联合类型或传入无效查询参数。修复测试夹具，不改变推理或会话行为。
2. **profile 与固定插件不一致**：插件 CI 更新后，中央 profile 版本及八个包摘要仍是旧值。重新生成并冻结 lock，新增版本与固定插件源码一致的测试；安装后校验全部八个包、588 个发布文件。
3. **会话插件在实际浏览器无法加载**：解压库默认入口将 Node `module` 带入浏览器产物。显式使用 `fflate/browser`，完整重编译后实际加载通过。组件单测不足以发现这一类构建入口差异。
4. **同一个预览重复执行**：全宽工作台与收起的详情栏同时加载同一文件；展开弹窗时底下也保留活跃预览。抑制全宽模式的详情预览，弹窗打开时卸载底层预览；新增同时包含 conversation/details 的组合测试，并实际断言只有一个 iframe。
5. **高 DPI 原生验收误报**：测试探针使用 96 DPI 固定坐标。改用真实标题栏尺寸及 WebView CSS/物理像素比例；生产标题栏实现未改。
6. **旧外观测试仍引用独立能力中心弹窗**：对齐现有设置页和通知入口，16 个浏览器用例通过。整包启动测试允许复用已校验 lock 与版本的测试依赖，不再强制用验收安装目录下的 npm 再安装一遍测试工具。

## 不应扩大理解的结论

- 本地 UI 使用测试与真实 35B 通过，不等于任意模型、驱动、复杂 Office 或无限长历史都无 bug。
- 全历史分页、恶意输入、取消竞态和错误分支主要依赖对应回归测试；没有用真实 35B 生成数万轮聊天来替代这些测试。
- OTA 下载、切换和回滚使用可控 fixture；没有发布新版本或替换用户安装来证明升级成功。
- 实际原生窗口的联网更新检查遇到 GitHub HTTP 403；单独核验响应确认匿名 API 配额剩余为 0。当前安装继续可用，未往产品注入个人 token，也未自动下载安装。不能把受控 OTA 测试通过说成这次联网更新全链路成功。
- 长测试路径下，捆绑 npm 的 Chalk `#ansi-styles` 解析报错；保留诊断证据。Agent 冷启动/移位启动本身通过，测试工具改为复用同 lock 的已安装依赖；没有宣称任意长路径下的全部 npm 生态命令均已验证。
- 没有使用真实手机跨网、第三方付费搜索、外部 TTS 或生产记忆库进行端到端测试；不能把插件加载成功等同于这些服务已验证。
- PPTX 仍是基础展示，复杂动画、SmartArt、字体和 Office 像素一致性不在承诺范围；大文件转换仍可能占用浏览器主线程。
- 既有客户端目录依赖门禁的 27 项问题没有纳入本轮修复，也没有宣称整个仓库全部门禁通过。

原生 Agent 以 connect 模式连接测试后端；关闭 Agent 后，后端健康检查仍为 200，确认没有误停外部引擎。测试结束后再由本轮任务单独关闭其自行启动的后端，不占用用户后续 GPU 工作。
