# MoE4All Agent 0.1.0-preview.1

独立 Agent 仓库的未公开构建候选。CI 生成了整包，但最终成功返回码误报为失败。
公开预览版见 [0.1.0-preview.2](0.1.0-preview.2.md)。

- 桌面窗口、首次启动和更新界面统一配色；中文与 English 可在设置中切换。
- 四种主题：白色（明亮），森林绿、黑色、灰色（黑暗）；可跟随系统明暗模式。
- 使用 DSH 原生设置与弹窗，标题栏同步主题；浏览器入口保留为简约地球图标。
- 随包包含固定版本的桌面运行时和八个内置插件，无需安装 Node 或构建源码。
- 推理 Engine 独立安装和更新，可导入已有 `infr.exe` 和本地 GGUF；不包含模型或 Engine 二进制。
- 用户数据、模型目录与缓存集中在安装目录；更新需要确认，滚动保留上一版本。
- CI 从 main 上的 `release-*` 标签构建，冻结依赖、校验运行时哈希，检查冷启动与移动目录后的启动。

下载 ZIP 后解压，打开 `MoE4All.exe`。Windows 需要 WebView2 Runtime；现代 Windows 通常已安装。
首次引导中选择安装 Engine 或导入已有 Engine，再选择模型。不要只复制单独 EXE。

这是预览版，建议先使用独立目录体验，不覆盖正在使用的 DSH 或旧 Agent 数据。
