# MoE4All Agent 0.1.0-preview.3

独立 Agent 仓库的首个公开 Windows x64 预览版。

- 桌面窗口、首次启动和更新界面统一配色；中文与 English 可在设置中切换。
- 白色（明亮），森林绿、黑色、灰色（黑暗）；可自动跟随系统明暗模式。
- 更新、语言和配色集中到 DSH 原生设置；标题栏同步主题，保留简约地球图标的浏览器入口。
- 包含固定版本的桌面运行时和八个内置插件，无需安装 Node 或构建源码。
- Engine 与模型不随包捆绑，可在首次引导中导入现有 `infr.exe` 和 GGUF，或按需安装 Engine。
- 数据、模型目录和缓存集中在安装目录；更新需要用户确认，滚动保留上一版本。
- main 标签触发 Windows CI，冻结源码、插件、运行时及部署依赖，并检查冷启动和移动目录后的重启。
- 更新器恢复调用方工作目录；原生工作区选择器默认定位到 Agent 自己的工作区。

下载 ZIP 后解压，运行 `MoE4All.exe`。需要 WebView2 Runtime；现代 Windows 通常已安装。
不要只复制 EXE；首次体验请使用独立目录，不覆盖生产 DSH 或旧 Agent 数据。

`preview.1` 和 `preview.2` 是未公开的构建候选；其 CI 分别定位到构建成功返回码、
连续执行更新器测试时的工作目录恢复问题，本版均已修正。
