# MoE4All Agent 0.2.0

- 新增内置能力中心：卡片展示 Agent、插件与 Engine，统一检查、确认下载、进度、重启生效和回退提示。
- Agent、插件与 Engine 可独立更新；自动检查不等于自动安装，预发布默认关闭，可跳过指定版本。
- 完全未配置 Engine 时自动安装最新正式版，不下载模型、不自动启动推理，也不接管已有外部服务。
- 统一中英界面和四种配色，改善文件选择、首次启动进度与窗口布局，并保存窗口大小和位置。
- 修复插件宿主依赖识别、升级快照、重启切换和失败恢复，提升更新后的可用性。
- 会话标题跟随主模型并关闭思考；同步八个维护插件的固定版本。
- Windows 整包由发布标签触发 CI 从源码构建，包含桌面壳与运行时，无需自行构建；Engine 与模型按需安装。

解压后运行 `MoE4All.exe`。升级下载安装需确认，数据与缓存保留，滚动保留上一版本。
需要 WebView2 Runtime。本次发布不包含新的 GPU 推理性能结论。
