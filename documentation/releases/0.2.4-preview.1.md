# MoE4All Agent 0.2.4-preview.1

这是相对正式版 0.2.1 的功能与体验 beta，使用现有兼容的 `preview` 标签规则。请在能力中心开启「包含预发布」后手动检查；下载、安装与重启仍需用户确认。稳定通道不会自动接收本版本。

## 新内容

- 可搜索的用户问题目录，点击返回原消息。
- 文件复制或原路径引用，工作台支持文本、代码、Markdown、图片、本地 HTML 和基础 PPTX 预览。
- 按轮次查看工具修改 diff，查看只读 Git graph、状态及文件 diff。
- 通用 API 模型可配置思考开关、档位和 wire value；pi-ai 提供商可显式选择请求协议。
- 新增浅层 `list_directory` 和按需 `shell_environment`，减少递归扫描和盲目尝试解释器。

## 修复

- 桌面工具问答后卡顿、输入或提交超时；保留原生标题栏拖动、硬件加速和无障碍功能。
- 启动进度过早完成、黑屏无恢复入口，以及配置路径迁移丢失 YAML 表达式标签。
- 停止生成后请求等待不结束、文件引用草稿丢失、子目录产出链接无效、重复后台预览及模型操作失败后控件卡住。
- PowerShell 完成状态与执行结果提示、Python 子进程 UTF-8、read-only 编码初始化兼容和超长单行续读。
- workspace-write 的 uv/pip/npm 默认缓存改用已有私有临时目录，不扩大权限。
- 高层滚动条配色、子代理菜单 key，以及测试和开发工具的 Git 仓库边界。

## 发布与验证

- Windows 整包由标签触发的 GitHub Actions 冻结构建，先生成 draft；冷启动、移位启动、插件来源及 OTA 切换/回退门禁通过后再公开同一份 CI 资产。
- 发布前已有隔离 35B 功能验收，以及浏览器/原生桌面 19 项模拟 API 验收。模拟验收不代表真实模型性能或所有驱动稳定性。
- Agent 与八个维护插件各自复用下载缓存；没有升级 DSH 会话格式，也不捆绑更新 Engine。

## 已知限制

- Windows 现有沙箱下 Node/MSYS 的部分管道操作仍可能拒绝访问，Schannel/SSPI 与交互凭据流程尚未解决；没有静默转宿主执行或扩大授权。
- 强制结束进程后的遗留配置写锁尚无自动恢复机制。
- PPTX 为基础预览，不承诺复杂动画或 Office 像素一致性；Word/Excel 不属于本次支持范围。
- 产出文件链接依赖成功工具操作的位置记录，未覆盖所有 shell 间接创建的文件。
- GitHub 匿名 API 配额或网络限制可能导致更新检查失败，失败不触发自动安装。
