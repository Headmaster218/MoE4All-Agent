# DSH 功能选择：1–24 项

本轮保持当前固定 DSH，只实施明确项，不做整体版本迁移。状态指本地源码及对应单元测试，不代表已发布。使用方式、权限和限制见[会话导航与文件工作台](../guide/conversation-workbench.md)。

| 编号 | 主题 | 本轮结论 |
| --- | --- | --- |
| 1 | 长会话体验 | 已按需求收敛为可搜索的全会话用户问题目录；未移植上游全部长会话存储优化 |
| 2 | 文件输入 | 已支持原生选择/拖入、复制到工作区或引用原路径；手机插件不动 |
| 3 | 停止、队列、重试/流状态 | 已排查；复现并修复 SDK 忽略 abort 时 next/return 卡住请求的具体问题；队列及共享重试语义未改 |
| 4 | 工作区文件工作台 | 已有文件标签、代码/文本/Markdown/图片及本地 HTML/PPTX 基础预览；其余 Office/PDF 内建渲染保留待办 |
| 5 | 文件修改/diff | 已有按轮次的成功 tool diff 记录；仅覆盖已加载历史，不含撤销或完整变更数据库 |
| 6 | 历史消息导航/编辑 | 与 1 合并完成问题定位；不改 EasyRewrite，不新增直接改写旧消息或任意旧消息 fork |
| 7 | 输入草稿与引用保留 | 确认当前版本存在工作区切换丢失规范引用的问题，已小修并补复现测试 |
| 8 | 交互式用户终端 | 暂缓，不增加新终端/PTY 架构 |
| 9 | Office 文档预览 | PPTX 作为 4 的基础能力落地；Word/Excel、旧 PPT 和高保真复杂效果待定 |
| 10 | 本地语音输入 | 保留未来插件 + MoE4All 后端方向，本轮不接入 |
| 11 | 更完整的子 Agent 预设/管理 | 待讨论，不把当前基础子 Agent 能力等同于新版完整功能 |
| 12 | 通用 API 模型思考能力 | 已有逐模型继承/关闭/自定义 reasoningEfforts、wire value 与保存校验 |
| 13 | 字体、快捷键、阅读宽度等 | 暂缓，不作为本轮独立改造项 |
| 14 | MCP resources/templates 等 | 待明确实际需求；不等同于已有 MCP tools 桥接 |
| 15 | 浏览器能力 | 已加入本地内容展示子集，HTML/PPTX 与宿主隔离；联网浏览器、自动化操作和登录态管理待定 |
| 16 | Git/worktree | 已有只读 Git graph、状态、文件 diff；worktree 隔离、stage/commit/revert 待讨论 |
| 17 | SSH 远程工作区 | 暂缓，不修改远端执行与文件系统权限模型 |
| 18 | 持久 Node/代码执行 REPL | 待讨论用途和执行隔离，不直接新增运行时 |
| 19 | 动态提示词/工具及缓存保持 | 待按请求协议和缓存事实评估，本轮不动后端 |
| 20 | 插件热重载/依赖同步 | 暂缓；现有需确认的 OTA 与重启机制不变 |
| 21 | Computer Use | 待明确工具、权限、审批和平台范围 |
| 22 | 原始日志/开发工具界面 | 暂缓，保留现有日志能力 |
| 23 | 思考内容翻译等 | 暂缓 |
| 24 | 新模型/Search/Fetch 等 API 扩展 | 本轮未选，按实际服务需求另行决定 |

## 这轮没有改变什么

八个维护插件未增加业务功能；手机连接、记忆、EasyRewrite、市场、插件 OTA 及引擎 OTA 都不是本轮改造范围。没有更换 DSH 上游基线或会话格式，没有复制生产 DSH profile，没有启动/停止现有引擎。之前已获授权提交的插件 CI gitlink 更新单独保留，不与本轮功能实现混为一谈。

停止修复保证调用方能结束等待，不能承诺任意不合作的第三方 SDK 已释放全部底层资源。PPTX 是基础展示能力，未标作完整 Office 支持；Git graph 也不替代 worktree 隔离。
